Equivalence of Locally Connected Definitions

I usually like to play with definitions. Given two definitions, I enjoy figuring out which one is stronger, which one is weaker, or whether both are actually equivalent. I recently found one such problem regarding locally connected spaces.

Let's define two definitions for a locally connected space (LCP):

Def 1: A topological space $X$ is said to be locally connected if for each $x \in X$ and for each open neighbourhood $U$ containing $x$, there exists a connected neighbourhood $V$ such that $x \in V \subseteq U$.
Def 2: A topological space $X$ is said to be locally connected if for each $x \in X$ and for each open neighbourhood $U$ containing $x$, there exists a connected open neighbourhood $V$ such that $x \in V \subseteq U$.

Question: Are Def 1 and Def 2 equivalent?

Def 2 definitely implies Def 1. The interesting part is proving the reverse.

Solution Roadmap

Let Def 1 hold.

  1. Step 1: Show each connected component is open.
  2. Step 2: Each open set $U$ is a locally connected space (LCP).
  3. Step 3: By Step 1, each connected component of $U$ is open.
  4. Step 4: Now for each $x$ and for each open neighbourhood $U$ of $x$, take $V$ as the connected component of $x$ in $U$. It is open since it is open in $U$.
