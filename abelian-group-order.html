Elements of a Finite Abelian Group

A proof without invoking Lagrange's Theorem

This is a wonderfully elegant trick. While it is standard to use Lagrange's Theorem to state that the order of an element divides the order of the group, for finite Abelian groups, we can prove this directly using a clever multiplication argument.

Theorem Let $G$ be a finite Abelian group of order $k$. For any element $g \in G$, we have $g^k = e$, where $e$ is the identity element of $G$.
Proof.

Let the elements of our group be $G = \{a_1, a_2, \dots, a_k\}$. Since $G$ is finite, we can define a single element $x \in G$ to be the product of all elements in the group:

$$x = a_1 a_2 \cdots a_k$$

Now, let $g$ be any arbitrary element in $G$. Consider the set formed by multiplying every element of $G$ by $g$:

$$S = \{g a_1, g a_2, \dots, g a_k\}$$

Because multiplying by a group element is a bijection (specifically, a permutation of the group), the set $S$ is exactly the same as the set $G$, just listed in a different order. Therefore, the product of all elements in $S$ must equal the product of all elements in $G$.

Evaluating the product of all elements in $S$, and heavily using the fact that $G$ is Abelian (so we can rearrange the terms), we get:

$$(g a_1)(g a_2) \cdots (g a_k) = g^k (a_1 a_2 \cdots a_k) = g^k x$$

Since the product of the elements in $S$ equals the product of the elements in $G$, we can equate them:

$$g^k x = x$$

Finally, we multiply both sides on the right by $x^{-1}$, yielding:

$$g^k = e$$

$\blacksquare$
